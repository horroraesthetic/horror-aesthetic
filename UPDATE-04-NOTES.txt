HORROR AESTHETIC — UPDATE 04
DIRECTOR ARCHIVES + HORROR TIMELINE

New modules:
1) /directors/
   - 94 director entries derived from existing review metadata
   - Search by director and film title
   - Expandable filmographies with release years and direct links to review dossiers
   - Filter by minimum number of represented films
   - Sort by name or number of films
   - English/Russian interface

2) /timeline/
   - Chronological view of 128 film dossiers represented in the review archive
   - Grouped by release year
   - Search by film, Russian title, director, or year
   - Filter by decade and sort oldest/newest
   - English/Russian interface
   - Clearly labelled as the chronology of currently reviewed films, not a complete history of horror cinema

Integration:
- New homepage research cards
- Cross-navigation between The Dark Archive, Director Archives, and Horror Timeline
- New URLs added to sitemap.xml
- Service Worker cache updated to ha-v156
- Shared reading/accessibility enhancements included

Install:
Upload the contents of this ZIP into the repository root and replace existing files.
Do not upload the ZIP itself into the website root.
Only the newest update ZIP is needed; it contains the complete current project.
